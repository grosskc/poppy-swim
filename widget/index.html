Poppy Swim

Add the meet widget to an iPhone

This shows her current meet — event, heat, and lane, plus her best and goal times. It updates from the same family dashboard, and you do not need an App Store listing or a developer account.

  1. 1

    Install Scriptable

    Scriptable is a free app that can show a small widget on the Home Screen. Install it from the App Store on each iPhone or iPad that should have the widget.

    Get Scriptable on the App Store
  2. 2

    Add the Poppy Swim script

    On the same device, tap the button below. Scriptable will open with a short installer. Tap Add (or Done), then tap the play button once. That saves a script named Poppy Swim.

    Add Poppy Swim to Scriptable

    If you already have it, you can tap this again and run it to get the latest script. You must open this page on the iPhone itself, not by sending the link to a computer.

  3. 3

    Put it on the Home Screen

    • Long-press an empty area of the Home Screen until the apps jiggle.
    • Tap the + button in the corner.
    • Search for Scriptable and choose a size: small, medium, or large.
    • Tap Add Widget, then tap the new widget and choose the Poppy Swim script.
    • Tap the background when you are done.

    Tapping the widget opens the family dashboard. The medium size is a good starting point — it lists the day’s events.

  4. 4

    Optional: add it to the Lock Screen

    • Long-press the Lock Screen and tap Customize, then Lock Screen.
    • Tap a widget area, choose Scriptable, and select Poppy Swim.

    The rectangular Lock Screen size works best. A one-line version is also available.

What it looks like

These previews use the current meet from the dashboard. The widget on a phone may take a little while to refresh after a change.

If the button in step 2 does not open Scriptable

You can add the script by hand. In Scriptable, tap + to start a new script, delete any sample text, and paste the contents of the widget script. Name it Poppy Swim and tap Done. Then go back to step 3.
