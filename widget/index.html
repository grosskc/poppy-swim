Poppy Swim

Add the meet widget to an iPhone

This shows one day of her current meet — event, heat, lane, stroke, and her best time. It updates from the same family dashboard, and you do not need an App Store listing or a developer account.

  1. 1

    Install Scriptable

    Scriptable is a free app that can show a small widget on the Home Screen. Install it from the App Store on each iPhone or iPad that should have the widget.

    Get Scriptable on the App Store
  2. 2

    Add the Poppy Swim script

    On this iPhone, tap the button to copy a short installer. Open Scriptable, tap + to start a new script, paste the code, and tap the play button once. That downloads the widget and saves it as Poppy Swim. You can then delete the installer script.

    If Scriptable already opened an empty script, paste into that one, run it, and then delete it.

    let fm
try {
  fm = FileManager.iCloud()
  fm.documentsDirectory()
} catch (e) {
  fm = FileManager.local()
}
const code = await new Request("https://grosskc.github.io/poppy-swim/widget/PoppySwim.js").loadString()
fm.writeString(fm.joinPath(fm.documentsDirectory(), "Poppy Swim.js"), code)
const a = new Alert()
a.title = "Poppy Swim installed"
a.message = "Now add a Scriptable widget to your Home Screen and pick Poppy Swim."
a.addAction("OK")
await a.presentAlert()
Script.complete()

    After this version is installed, the widget checks for a new script about once a day and updates itself. If your phone still has an older copy, run the installer once more so that self-update is in place.

    Download a Scriptable file

    If you prefer, download that file, then share it and open it in Scriptable.

  3. 3

    Put it on the Home Screen

    • Long-press an empty area of the Home Screen until the apps jiggle.
    • Tap the + button in the corner.
    • Search for Scriptable and choose a size: small, medium, or large. Large shows a full day; medium shows the next three races.
    • Tap Add Widget, then tap the new widget and choose the Poppy Swim script.
    • Tap the background when you are done.

    Tapping the widget opens the family dashboard. Leave the Parameter set to auto to follow the current day of the meet.

  4. 4

    Optional: swipe between days

    Scriptable can’t swipe inside one widget, but iOS can stack two of them. Add two large Poppy Swim widgets, then:

    • Long-press one widget and choose Edit Widget.
    • Set Parameter to sat or sun (or day1 / day2 for other meets).
    • Do the same for the second widget, using the other day.
    • Drag one widget onto the other to make a Smart Stack, then swipe up or down to change days.

    A single widget left on auto switches to the current day of the meet on its own.

  5. 5

    Optional: add it to the Lock Screen

    • Long-press the Lock Screen and tap Customize, then Lock Screen.
    • Tap a widget area, choose Scriptable, and select Poppy Swim.

    The rectangular Lock Screen size works best. A one-line version is also available.

What it looks like

These previews use the current meet from the dashboard. The widget on a phone may take a little while to refresh after a change.

The widget reads the current meet file on this site. It does not submit meet entries. For the full schedule and notecards, use Poppy’s dashboard.
